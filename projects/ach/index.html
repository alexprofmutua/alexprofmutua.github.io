Desktop app / study timer

After Class Hours (ACH)

See how much time you spend studying each course.

Swift · SwiftUI · AppKit · SQLite · Electron

View ACH on GitHub ↗ (opens in a new tab)

Screenshots

Track a study session

Pick a course and count up, or start a countdown for a set study block. When the countdown ends, ACH keeps recording overtime. A floating timer keeps the session visible while you work in another app.

Study history records completed sessions. On Mac, you can set daily, weekly, monthly, or semester goals for one course or for all courses.

How it works

The Mac app uses SwiftUI for the main workspace and AppKit for the desktop timer. A shared timer service tracks active study segments, which are stored in SQLite and used to calculate course totals and goal progress.

ACH saves progress about every 15 seconds while the Mac timer is running. After a crash, it restores the last checkpoint as a paused session. Study data stays on the device, and a JSON backup can move records between the Mac and Windows editions.

Platforms

The native app runs on macOS 14 or later. Building it requires Swift 6 and the macOS 26 SDK. The Electron edition is available as an unsigned x64 Windows preview.
