A home for everyday links

I built Control Center to keep frequently used links in one place. The sidebar separates coding resources, games, finance, Williams College links, reading, and entertainment into their own pages.

Each page uses a simple list of bookmarks. Links open in a new tab, so the hub stays available while I browse.

How it works

Static HTML pages share a CSS layout with a fixed sidebar and Lucide icons. JavaScript sorts bookmark lists alphabetically and counts how often each link is opened, including middle-clicks.

Click counts are saved in the browser with localStorage. If browser storage is unavailable, the counter continues working for the current page.

Run locally

Download or clone the repository and open index.html in a browser. No build step or database is required. The icons load from a CDN.
